# Lightning

Актуальный комплект аттракциона Lightning и интеграции StriveX.

- `Game/` — Windows/Electron-приложение аттракциона, интерфейс двух экранов, игровые режимы и Arduino-прошивка.
- `StriveX/` — сервер, станционный Gateway и клиент протокола StriveX.

Рабочие файлы `.env` не публикуются. Для первоначальной настройки используйте файлы `.env.example` и документацию внутри соответствующих каталогов.
