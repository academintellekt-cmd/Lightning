LIGHTNING AUDIO FILES

Place your MP3 files in this folder:

menu.mp3       - fallback menu music when music/menu is empty
game.mp3       - looping game-session music
end.mp3        - game-session ending music
button.mp3     - every game-button press
bonus.mp3      - bonus-button pickup
countdown.mp3  - each of the final 5 seconds and the 3-2-1 start countdown
red.mp3        - red color sound
blue.mp3       - blue color sound
green.mp3      - green color sound
yellow.mp3     - yellow color sound
purple.mp3     - purple color sound

Missing files are allowed. The game continues without that sound.
File names and volume levels can be changed in config.json.

MENU PLAYLIST

Place any number of MP3, WAV, OGG, M4A or AAC files in:
music/menu

They are sorted by filename and played in that order in a loop.
Use names such as 01_intro.mp3, 02_menu.mp3, 03_attract.mp3.
start-countdown.mp3 - separate sound played once before the 3, 2, 1 countdown.
