# Lightning 2.0.2

- Стартовая подсветка режима «Поймай свой цвет» отправляется повторно после перехода Arduino в игровой режим.
- Синяя и оранжевая панели запускаются одновременно.
- В «Поймай пересечение» совпавшая кнопка фиксируется на 0,5 секунды.
- Балл начисляется только за нажатие точной кнопки, на которой совпали оба диода.
- Оба движущихся диода каждой панели имеют цвет соответствующего игрока.
- Информационные анимации используют дискретное переключение кнопок.
- Руки в демонстрациях закреплены на тех кнопках, которые они нажимают.

Для работы обновлений заново прошейте Arduino скетчем `V5.2` из папки `arduino`.
