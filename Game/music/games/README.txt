Создайте внутри этой папки следующие каталоги и положите музыку:

classic       - Раунды
replacement   - Бесконечный набор
independent   - Независимая гонка
duel          - Дуэль
colorMatch    - Цветовой код
colorSequence - Световая мелодия

Если папка режима пустая, используется общий плейлист music/game.
