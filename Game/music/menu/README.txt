Положите в эту папку музыку для меню.

Поддерживаются файлы:
MP3, WAV, OGG, M4A, AAC.

Треки сортируются по имени и воспроизводятся по очереди.
Для явного порядка используйте имена:
01_intro.mp3
02_menu.mp3
03_attract.mp3

После последнего трека плейлист начинается заново.

При сборке build-exe.bat эта папка копируется в dist\music\menu
рядом с готовым Lightning Attraction.exe.
