# Lightning 2.0.1 — исправления игровых режимов

## Что исправлено

- В режиме «Захват цвета» таймер показывает оставшееся время текущего 30-секундного раунда.
- После каждого раунда обе панели дважды мигают цветом победителя. При ничьей используется белый цвет.
- Новый раунд начинается после завершения световой индикации.
- В 2D-пинг-понге ракетка принимающего игрока появляется не ближе пяти светодиодов от края входа мяча.
- В режиме «Поймай пересечение» координаты обеих панелей передаются Arduino одной командой. Движение оранжевых диодов восстановлено.
- Два бегущих диода реже синхронизируются: при близком движении в одну сторону один меняет направление и скорость.
- В режиме «Поймай свой цвет» состояние обеих панелей передаётся одной командой. Исправлены подсветка синего игрока и синхронизация цвета с обработкой нажатия.
- Во время красной или зелёной индикации повторные нажатия временно блокируются.
- Переключатель языка использует нарисованные флаги вместо emoji, поэтому Windows больше не заменяет их буквами.
- Обновлены информационные анимации четырёх новых режимов.

## Обязательное обновление Arduino

Прошейте Arduino Nano скетч:

`arduino\Lightning_LED_Controller_Nano\Lightning_LED_Controller_Nano.ino`

Версия протокола контроллера: `V5.1`.

Добавлены команды:

```text
ROUNDWIN B|O|D
CATCH2 bluePosition bluePhase blueMask orangePosition orangePhase orangeMask intervalMs
DOTS2 blueDot1 blueDot2 orangeDot1 orangeDot2
```

Старая прошивка не сможет корректно обработать синхронную подсветку новых режимов.

## Запуск

Запустите `start-dev.bat` из папки игры. При первом запуске установка компонентов может занять несколько минут.
