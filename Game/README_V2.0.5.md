# Lightning 2.0.5

## Музыка

- Каждый новый переход отменяет незавершённый предыдущий переход.
- Меню, игра и экран завершения больше не могут одновременно управлять громкостью одной дорожки.
- Повторный переход в тот же режим возобновляет музыку, если браузер ранее заблокировал её запуск.
- Ручное завершение игры гарантированно переключает игровую музыку на меню.

## Цветовой код

- COM-команды отправляются через очередь с интервалом 12 мс и больше не переполняют 64-байтный буфер Arduino Nano.
- Комбинации и кнопки подтверждения появляются у обоих игроков.
- Нажатия корректно меняют цвета LED.
- Кнопка 8 светится постоянным белым цветом без фоновой анимации.
- При смене режима или выходе кнопка 8 принудительно очищается.
- Устаревшие команды предыдущего режима удаляются из очереди.

Для этой версии требуется прошивка Arduino `V5.5`.
