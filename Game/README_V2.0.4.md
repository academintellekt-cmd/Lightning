# Lightning 2.0.4

- Кнопка завершения сессии приведена к общему стилю и получила контурную иконку.
- Все кнопки правого столбца выбора игр имеют оранжевое оформление.
- На экране готовности и во время игры добавлено безопасное завершение выбранной игры с подтверждением.
- Индикация правильного и неправильного нажатия на Arduino стала неблокирующей и независимой для двух игроков.
- Нажатие в «Поймай свой цвет» больше не перезапускает цветовой цикл соперника.
- В «Цветовой мелодии» убрана подсказка о кнопке 8.
- В «Цветовом коде» комбинации удалены с монитора: они показываются только физическими кнопками.
- Исправлены последующие раунды «Цветового кода», смена цветов и подтверждение кнопкой 8.
- Все информационные слайды переведены на общий SVG-стиль с точными позициями рук и кнопок.

Для этой версии обязательно прошейте Arduino скетчем `V5.4`.
