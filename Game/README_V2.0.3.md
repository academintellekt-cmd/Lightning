# Lightning 2.0.3

## Цветовой код

Плавное гашение LED-панелей больше не блокирует Arduino. Во время анимации контроллер продолжает читать COM-порт, поэтому команды ввода и смены цвета не теряются.

Команды `COLORS`, `COLORS2` и смена игрового режима принудительно завершают старые фоновые LED-эффекты.

## Цветовая мелодия

Кнопка 8 исключена из создаваемых последовательностей. Ответ проверяется автоматически после ввода всей последовательности, отдельное подтверждение не требуется.

## Информационные слайды

Четыре последних режима получили самостоятельные SVG-анимации:

- «Захват цвета» показывает перекрашивание общей позиции двумя игроками;
- «Поймай свой цвет» показывает смену цвета, точное нажатие и появление следующей цели;
- «Поймай пересечение» показывает две дискретно перемещающиеся точки, задержку в общей позиции и нажатие;
- «2D Пин-понг» показывает подачу, переход мяча между полями и ответное нажатие.

Для этой версии требуется прошивка Arduino `V5.3`.
